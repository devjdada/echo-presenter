# 01 — Product Vision

> **AI-Powered Intelligent Live Presentation & Production Platform**

---

## What Is EchoPresenter?

EchoPresenter is a **Windows-first, native desktop application** that unifies:

| Capability | Inspiration |
|---|---|
| Slide/presentation engine | ProPresenter |
| Live visual effects & composition | Resolume Arena |
| Bible search, translations & display | BibleShow + EasyWorship |
| Real-time sermon transcription & scripture detection | Pewbeam + Rhema + RhemaPresenter |
| AI-driven content creation & live production control | *Original — no existing product does this fully* |

---

## Core Differentiator

> **AI doesn't just generate content for EchoPresenter. AI *operates* EchoPresenter.**

- ChatGPT / Gemini / Claude / Antigravity can connect to EchoPresenter via MCP and create entire services
- An AI agent can control the live production — switch backgrounds, display scriptures, manage media
- EchoPresenter listens to sermons and automatically detects and displays Bible references
- Real-time **Quotable Quotes** extraction turns powerful sermon moments into branded lower-thirds and graphics — instantly
- An operator can control everything manually, via AI chat, voice commands, keyboard, Stream Deck, or external integrations

---

## Target Markets (phased)

1. **Phase 1:** Churches (worship, sermons, announcements)
2. **Phase 2:** Conferences and events
3. **Phase 3:** Broadcast studios and live production
